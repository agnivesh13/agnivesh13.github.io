# Event photos

Drop the photos from the matching LinkedIn posts here, using these exact
filenames. Each card picks its image up automatically — no code change needed.

| File                      | Event                                    |
| ------------------------- | ---------------------------------------- |
| `aws-trading-bot.jpg`     | Trading Bot in Production on AWS         |
| `pfsense-homelab.jpg`     | Zero-Trust Home Network with pfSense     |
| `nexovate-hackathon.jpg`  | Nexovate'25 Hackathon                    |

Until a file exists, the card renders a designed gradient panel with the event
icon instead — it never shows a broken image.

**Recommended:** landscape, roughly 3:2 or 16:9, at least 800px wide, and
compressed to under ~250 KB so the page stays fast.
